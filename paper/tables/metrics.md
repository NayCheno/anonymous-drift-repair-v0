# Metrics Table

| Metric | Purpose |
|---|---|
| Task Success | Measures final completion |
| State Consistency | Measures trajectory-level conflicts |
| Goal Consistency | Checks current objective alignment |
| Constraint Consistency | Checks active constraints |
| Evidence Faithfulness | Checks support by evidence |
| Tool-State Consistency | Checks action validity under tool outputs |
| Abstention Calibration | Checks answer/clarify/refuse decision |
| Recovery Rate | Measures repair benefit on failed cases |
| Over-Repair Rate | Measures harm to originally correct cases |
| Repair Cost | Measures extra tokens/retrievals/tools |
